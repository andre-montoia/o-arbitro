# O Arbitro Design System v1.0.0

## Theme
- **UI:** Dark premium
- **Background:** Deep purple
- **Accents:** Gold, pink, emerald
- **Typography:** Syne & Space Grotesk
- **Effects:** Glassmorphism (BackdropFilter), neon glow shadows

## Existing Components

### GlassCard
- **Variants:** 5 (e.g., small, medium, large, active, inactive)
- **New Variant:** `glowing` - animated glow effect
- **Description:** Basic card component with glassmorphism effect.

### ArbitroButton
- **Variants:** 4 (e.g., primary, secondary, disabled, icon-only)
- **New Variant:** `emerald` - button with an emerald green gradient and glow
- **Description:** Interactive button component with various styles.

### ArbitroBadge
- **Description:** Small informational badge.

### ScoreHud
- **Description:** Head-up display for scores.

### SlotMachine
- **Description:** Game component.

### DareResultOverlay
- **Description:** Overlay displaying dare results.

### AvatarIcon
- **Description:** Shared widget for player avatars.
